MokaBot

Firmware installer

Supported boards
  • WT32-SC01 (not the WT32-SC01 Plus)
  • Waveshare ESP32-S3-Touch-LCD-3.5B
The board is detected when it connects; the matching firmware is installed.
Install
  1. Connect the board to this computer with a USB data cable.
  2. Press the button and choose the board's serial port.
  3. When asked whether to erase the device: erase on a new board; don't erase to update a MokaBot and keep its WiFi, settings, calibration and saved brews.
This browser cannot flash boards: use Chrome, Edge or Opera on a computer. Flashing needs a secure page: open it over https:// (or from localhost).
Not connecting?
  • Try another cable: some USB cables only charge.
  • WT32-SC01 on Windows: install the USB serial driver (CP210x or CH340, depending on the board) if no port appears.
  • Put the board in download mode: hold BOOT, press and release RESET, release BOOT, then press the button again.
  • Close any serial monitor (PlatformIO, Arduino IDE) using the port.

Already running MokaBot? It can also update over WiFi: long press the colour button on the screen, or upload the .bin from the settings page.
