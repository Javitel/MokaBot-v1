ES8311 audio codec driver, used by the Waveshare ESP32-S3-Touch-LCD-3.5B
build for the button beep.

Espressif's `esp_codec_dev`/`es8311` component (Apache-2.0, see the SPDX
headers), as adapted to Arduino `Wire` by Waveshare in
https://github.com/waveshareteam/ESP32-S3-Touch-LCD-3.5B (Arduino/libraries/es8311).
Ignored by the WT32-SC01 environment (`lib_ignore` in platformio.ini).
